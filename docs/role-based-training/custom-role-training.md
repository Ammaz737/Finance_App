# Custom role training worksheet

[Master training index](README.md)

Custom roles are implemented, but the live role records were not queried. This is a worksheet for each organization-defined role, not an invented fifth seeded role.

1. Administrator opens Company → Roles and the actual role details. Record its name, permissions, default scope, and assignments.
2. Match each granted page to the relevant procedures in Owner/Finance Admin, Manager, or Employee training. Read and practice only the granted procedures.
3. Record exact routes, create fields, permitted actions, restricted actions, entity boundaries, and next-role handoffs for this role.
4. Check approval eligibility separately from permission keys. A custom finance-like role does not automatically qualify for a finance/AP step by its name.
5. Exercise one allowed record, one out-of-scope record, and one denied action in a test account. Record observed outcomes; code-verified defaults do not prove current database assignments.
6. Add a role-specific manual named for the actual configured role after verifying it, using this worksheet and the checked procedures. Do not label the worksheet a completed guide for unknown live roles.
